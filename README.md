# Ghan Sarvo 2

GitHub-ready Android WebView project for live Vedic transit / Sarvatobhadra exploration.

- App name: Ghan Sarvo 2
- Application ID: com.ghan.sarvo2
- Swiss Ephemeris REST API + Lahiri sidereal
- Internet permission required
- GitHub Actions builds a debug APK

## Build
Push this folder to a GitHub repository and run **Actions → Build APK**. The APK is uploaded as an artifact.
